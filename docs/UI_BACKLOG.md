# UI 개선 메모 (전체 UI 수정 때 반영)

사용자가 실제로 써 보며 헷갈린 점과, 테스트 중 확인된 표시 문제를 모은다. 수정은 전체 UI 정리 때 한꺼번에 한다.
(작성 2026-10-07)

## 로비 카드

1. **바이인과 시작 스택이 헷갈린다.** 카드의 "1,000 칩 / 5,000 칩"은 바이인(참가비)인데 시작 스택으로
   읽혔다(표준이 10bb, 딥이 50bb 로 보임). 실제 시작 스택은 턴보 20,000(100bb), 표준 30,000(150bb),
   딥 60,000(300bb). → 카드에 **시작 스택(bb)** 을 바이인과 구분해 보여 주고, 바이인에는 "참가비" 라벨.
2. **계산이 아직 안 된 진행 중 대회가 Lv 1 · 0분으로 보인다.** 늦게 설치했거나 백그라운드가 아직 따라잡지
   못한 대회는 시작 상태가 그대로 표시된다(예: 16:00 딥을 16:45 에 보면 Lv 1 · 0분 · 179/180).
   → 대회 시각과 계산된 진행 시각이 크게 다르면 "진행 계산 중"으로 표시.
3. **'전체' 필터에 진행 중(등록 마감) 대회가 안 보인다.** '진행' 탭을 눌러야 보인다. 의도인지 정리 필요.
4. 좁은 카드에서 "9-MAX · 15분", "Lv 6 · 400/800" 이 줄바꿈된다. 칸 구성/글자 크기 정리.

## 대기실(늦은 등록·입장)

5. **동기화 %가 0% 에서 오래 멈춘 것처럼 보인다.** 계산량이 큰 대회(실제 봇으로 도는 딥, 폰 CPU)는 첫 계산
   묶음이 끝나기 전까지 0% 로 남는다. → 예상 남은 시간이나 "계산 중(대회 N분 중 M분)" 같은 진행 표시,
   너무 오래 걸리면 다른 대회를 권하는 안내.
