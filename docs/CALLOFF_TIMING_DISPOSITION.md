# 올인 콜 판단과 생각 시간의 성향 일치

요청: 기존 시간 모델의 좋은 부분을 유지하면서, 확률·상대 비교보다 운에 기대는 콜이 숙련자의 긴 분석처럼 보이는 문제를 보완한다. K8o/30bb/9-max를 시간 제한의 특별 조건으로 만들지 않는다.

## 적용 경계

프리플랍에서 실제 선택이 call이고, 최종 판단 경계가 defend_calloff(legacy percentile 콜오프)일 때만 적용한다. layer-equity/가격 계산이 실제 행동을 결정한 calloff_layer, 일반 디펜스, 폴드, 오픈/레이즈, 포스트플랍 및 개념 없는 구형 프로필은 기존 수식을 유지한다. 계산을 shadow로 했다는 사실만으로 깊은 계산이 실제 적용됐다고 취급하지 않는다.

## 기존 성향을 쓰는 수식

L = clamp(looseness/10, 0, 1)
G = clamp(gamble/10, 0, 1)
Kdef = 기존 persona.concept_knowledge(profile, pf_defend)
impulse = L × G × (1 − Kdef)
effort = 1 − impulse
c_time = 기존 결정 근접도 c × effort

looseness는 기존 defend/calloff 범위를 넓히는 기질이다. gamble은 범위를 새로 넓히지 않고, 같은 콜을 얼마나 가볍게 실행하는지 시간에만 반영한다. pf_defend 지식이 높으면 도박성으로 해석하는 비중이 작아진다. 이 수식은 행동 원인의 인과적 분해가 아닌 성향 기반 시간 대용값이다. 새 성향·난수·패별 임계값은 없다. 계수는 초기 설계이며 실측 사람 행동에 맞춰 보정된 값이라고 주장하지 않는다.

기존 visible_seconds 함수의 근접도 입력만 c_time으로 교체한다. 따라서 경계 고민 D_c와 commit × c 증폭이 함께 감소한다. 기존 구조 복잡도·돈 압박·판단 숙련 평균, 익숙함 보정, pace/tank, tell masking/clock 습관, 지터, 1.5초 최소 표시, 타임뱅크 규칙은 유지한다. 고의로 기다리거나 느리게 행동하는 사람까지 모두 즉시 콜하게 만들지 않는다.

기록에는 원래 c, timing_c와 decision_effort(weight/source/impulse/사용 성향)를 함께 남긴다. 원래 판단의 경계를 덮어쓰지 않는다. 시간에 의한 타임아웃 여부는 기존 규칙대로 달라질 수 있으나, 타임아웃 전 전략 행동·RNG·콜 범위는 변경하지 않는다.

## 확인 결과

- 같은 경계 c=1, 같은 결정 시드와 성향(skill=2, loose=10, gamble=10)의 session 테스트: 기존 13.380973초 → 2.467871초. 두 경우 타임뱅크 사용 0초. 사용자 영상 핸드의 재현이 아니라 통제 테스트다.
- pace=1.5, tank=1, mask=clock=0, jitter=1, K=0.1, c=1, commitment=1의 수식 테스트: 20.912321초 → 1.5초; 타임뱅크 2.912321초 → 0초.
- 실제 defend_decision fixture: K♠ 8♥, BB vs UTG, 9-max, 스택 30bb, 올인 30bb, 콜 비용 29bb. 낮은 지식/높은 루즈함 프로필의 콜은 그대로 유지된다. 이 프로필에서는 원래 c=0으로 이미 쉬운 콜이라 본래부터 짧다. 해당 사례를 사용자 장면의 완전 재현이라고 주장하지 않는다.
- 루즈함·도박성이 각각 증가할 때 동일 조건의 시간은 늘지 않는다. 디펜스 지식이 높을수록 effort는 기존 모델 쪽으로 복원된다.
- 정확 계산 적용, 일반 디펜스, 폴드, 포스트플랍 대조군은 표시 시간 동일. 결정 난수 상태 동일 및 반복 결정성 확인.

검증: tools/verify_timing_calloff_effort.py, tools/verify_timing_familiarity.py. 전체 시간-전략 불변성 및 경계 출처 검증 결과는 실행 완료 후 아래에 추가한다.

경계 출처 검사: 프리플랍 3,534건(실제 layer 계산 적용 10건), 포스트플랍 응답 369건에서 경계 불일치 0건.
짧은 12-hand 불변성 검사에서 전략 다이제스트·타임아웃 이전 동작 동일성은 통과했지만, 강제 3초 시나리오에서 타임뱅크를 소진하지 못해 timeout coverage 조건은 미충족했다. 기본 40-hand 조건으로 재검증한다.

고정된 경계 c=1, commitment=1, K=0.3, 구조 복잡도 0.3에서 1,000개 기존 timing_traits(pid, seed=20261009)와 같은 지터를 비교했다. 기본 18초를 넘는 경우는 기존 703건 → 후보 3건이었다. 최대 표시 시간은 125.985988초 → 23.345970초. 이는 낮은 디펜스 지식/높은 루즈함·도박성의 통제 조건이며 실제 플레이 빈도가 아니다. 기존 느린 행동 습관과 지터를 유지하므로 모든 콜이 짧아지는 강제 상한은 아니다.
