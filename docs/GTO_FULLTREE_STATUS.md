3. **모으기·판정** — 보드 값과 트리에 쓴 값의 차이(D)가 오차 폭(U) 안인지, A·B 가 서로 맞는지 본다.
4. 통과 못 하면 표 = 0.5 × 이전 표 + 0.5 × 보드 값으로 바꿔 다음 단계(최대 0~3단계).
