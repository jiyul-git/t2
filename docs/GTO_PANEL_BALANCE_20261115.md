# 플랍 패널 숫자 치우침 진단과 균형 패널 (2026-11-15)

## 왜

60bb 4단계 빈도차트 시험본에서 UTG 레이즈가 22 100% / 33·44 1% / 55 100%, A5s 59% / A4s·A6s·A7s 0% 처럼 들쭉날쭉했다.
저장된 기대값 그대로라 손패 이름이 어긋난 것은 아니다. 값 자체를 의심했다.

## 1. 기존 패널(A·B 각 72장)의 숫자 비율

질감 12칸(무늬 같음/페어/무늬 다 다름/두 무늬 × A/KQ/J 이하) × 칸마다 6장 무작위. 숫자 비율은 통제하지 않았다.
가중치를 반영한 숫자별 출현 비율(1.00 = 실제):

| | 2 | 8 | T | 6 |
|---|---|---|---|---|
| 패널 A | 0.64 | 1.55 | 0.67 | 1.39 |
| 패널 B | 1.77 | 0.52 | 0.90 | 0.88 |
| A+B | 1.21 | 1.04 | 0.79 | 1.14 |

## 2. 실제 결과에서 확인 (60bb 4단계, 끝점 39개 × 자리 2 = 78)

같은 끝점을 A 72장, B 72장으로 푼 손패별 값 차이(bb). 숫자 보정 = 질감 칸 합은 유지하고 숫자 비율이 실제와 맞도록 가중치 재조정(rake.py).

| 손패 묶음 | 원래 | 숫자 보정 |
|---|---|---|
| 전체 평균 | 1.05 | 0.58 |
| 작은 페어 22~66 | 2.41 | 0.59 |
| 오프수트 잡패 | 1.49 | 0.83 |
| A2s~A9s | 0.66 | 0.50 |
| AK·AQ·KQ | 0.66 | 0.42 |

예: BTN 오픈 → BB 콜 끝점(s4_t01), BB 72o 값 A 0.83 / B 3.15 (사용값은 평균 1.99). BB 콜·폴드 경계는 0.1~0.3bb 라 이 오차가 결정을 바꾼다.
관찰: 100bb 1단계 BB 는 BTN 오픈(SB 폴드)에 폴드 0%, 60bb 4단계 16%.

## 3. 균형 패널 설계와 검증 (계산기 없이)

- 설계(design.py): 질감 12칸 × 6장 구조와 칸 가중치는 그대로. 숫자 비율 + 숫자 짝 비율이 실제(전체 22100 플랍)와 맞도록 담금질로 고름. 결과 bal_panels.json (BAL_A, BAL_B).
- 검증 척도(proxy.py, evalp.py): 169 손패별 플랍 맞음 특징 8개(셋/투페어/오버페어/탑페어/약한 페어/플러시/플러시 드로우/스트레이트·드로우 대략)의 확률을
  전체 22100 플랍으로 정확히 계산하고, 패널 추정과의 오차(%p)를 잰다. 설계 목표(숫자·짝 비율)와 다른 척도라 과적합 확인이 된다.
  특징 정의는 대략적인 대체 지표이며 실제 손패 값 오차를 직접 잰 것은 아니다.

| 패널 | RMS 오차 | 최대 오차 |
|---|---|---|
| 기존 A / B | 3.10 / 3.23 | 13.6 / 18.1 |
| 기존 A+B 평균 | 2.01 | 8.59 |
| 숫자 보정 A / B | 2.96 / 2.90 | 15.7 / 17.1 |
| 무작위 패널 30개 | 중앙 3.11 (2.51~3.74) | |
| **균형 A / B** | **1.59 / 1.46** | 9.6 / 7.95 |
| **균형 A+B 평균** | **0.99** | **4.97** |

- 가중치만 고치는 숫자 보정은 이 척도에서 거의 효과가 없다(숫자 비율만 맞고 짝·무늬는 그대로).
- 균형 패널 하나가 기존 A+B 평균보다 낫고, 균형 A+B 는 기존의 절반 오차. 비용은 같다(72장 × 2).

## 4. 실제 계산 확인 (2026-11-16)

같은 끝점(60bb 4단계 s4_t01, BTN 오픈 → BB 콜)을 균형 패널 X(BAL_A)·Y(BAL_B) 각 72장으로 풀었다. 솔버 설정은 예전과 같다(반복 1000, 목표 0.3% pot, 144장 모두 목표 안).
보드 결과는 `claude/ft60_baltest`(입력)와 `claude/ft60_board_71~75`(나눈 묶음)에 있고, X 앞 36장은 이 세션에서 풀었다(올리지 않음, 재현은 같은 입력으로).
그림: `out/gto_panel_balance_real.png`.

손패별 두 패널 값 차이 평균(bb):

| 손패 묶음 | BB 예전 A-B | BB 균형 X-Y | BTN 예전 A-B | BTN 균형 X-Y |
|---|---|---|---|---|
| 전체 169 | 0.62 | **0.16** | 0.46 | **0.12** |
| 작은 페어 22~66 | 1.59 | **0.31** | 1.22 | **0.17** |
| A2s~A9s | 0.37 | **0.09** | 0.32 | **0.09** |
| AK·AQ·KQ | 0.38 | **0.17** | 0.20 | **0.11** |
| 오프수트 잡패 | 0.84 | **0.19** | 0.60 | **0.13** |

- BB 72o: 예전 A 0.83 / B 3.15 → 균형 X 1.52 / Y 1.68.
- 예전 평균((A+B)/2)과 균형 평균((X+Y)/2)의 차이: BB 0.19bb, BTN 0.13bb. 예전 값은 평균을 내도 이만큼 치우쳐 있었다.
- 끝점 하나 결과다. 다른 끝점도 같은 방향일 것으로 보지만 재지 않았다.
- 판단: 다음 계산부터 균형 패널을 쓴다(prepare 의 패널 파일만 교체).
