# ft60 1단계 D/U 미통과 원인 진단 (2026-11-10, 계산 없이 하는 진단 (a)(b))

배경: 1단계 collect(커밋 a60dddb)에서 D≤U 통과 1/80자리(0단계 0/80), D/U 중앙값 4.47→3.75 이나 최악 8.6→10.9, 0·1단계 공통 끝점 37개 중 D/U 가 준 것은 10개. 문서 7장 "0→1단계에서 D/U 가 줄지 않음" 신호.
이 진단은 새 보드 풀이 없이 한 것이다. 2단계 입력은 만들지 않았다.

## 규칙 변경 기록 (사용자 결정, 다른 세션 경유로 전달됨)
- 1단계 트리 풀이 종료 기준을 문서 3장의 정확 gap ≤ 0.010bb 에서 "정확 gap < 0.02" 로 완화해 950회(gap 0.0193)에서 멈추고 보드를 돌렸다(`step1/convergence.json`).
- 진단 (a) 에서는 횟수 상한과 "50회 감소 < 10% 정지" 규칙을 없애고 정확 gap ≈ 0.007 까지 풀었다.

## (a) 트리 미수렴이 원인인가 — 아니다
- 1단계 표 그대로 950회 체크포인트에서 이어 풀어 1450회에서 정확 gap **0.00712**(0단계 0.00678 수준). 50회별 정확 gap: 1000 0.01713, 1050 0.01453, 1100 0.01305, 1150 0.01178, 1200 0.01072, 1250 0.00981, 1300(스킵) 0.00901, 1350 0.00829, 1400 0.00767, 1450 0.00712 (`step1/diag/`).
- 같은 끝점 40개의 도착 레인지를 1450회 트리에서 다시 내보내면 레인지는 950회 대비 꽤 움직인다(클래스 L1/이전 레인지 질량: 중앙값 5.2%, 90분위 10.1%, 최대 27.2%).
- 기존 1단계 보드 값 V1 은 그대로 두고, 새 레인지로 가중치(w)와 행렬 끝점의 상대 도착 분포만 바꿔 D/U 를 다시 계산:
  | | 950회 레인지(원래) | 1450회 레인지 |
  |---|---|---|
  | D≤U 통과 | 1/80 | 1/80 |
  | D/U 중앙값 | 3.75 | 3.71 |
  | D/U 최대 | 10.94 | 11.14 |
  | D 중앙값 | 1.780 | 1.719 |
  | 10% 넘게 바뀐 자리 | | 0 |
  A·B 복제 80/80 통과는 그대로.
- 한계: V1 은 950회 레인지로 푼 보드 값이다. 행렬 끝점은 새 분포를 곱해 다시 계산했지만 행렬 없는 끝점은 가중치만 바꿨다. 보드를 새 레인지로 다시 풀면 V 자체가 달라질 수 있는데, 그 효과는 이 진단에 없다(레인지 이동 5%대가 V 를 U 의 3.5배만큼 움직일 것 같지는 않다는 것이 추정이며 확인된 것은 아니다).
- 결론: 트리 미수렴은 D 의 주된 원인이 아니다.

## (b) T0→T1→V0→V1 : 반반 섞기 진동인가, V 자체가 큰가
- 0단계 표가 있던 끝점은 BB 씨앗 4자리(노드 844, 3905)뿐이다. 나머지 66자리(+정적 4자리)는 0단계에 표가 없었고, 문서 규칙대로 T1 = V0(전부 그대로)이다. 따라서 이 66자리의 1단계 D = |V1 − V0| = V 의 단계 간 이동량이다. (T1==V0 가 66/70 자리에서 성립, 나머지 4자리는 정적 끝점 노드 10·31.)
- V 이동량 |V1−V0| 중앙값 1.78 = U(중앙값 0.47)의 3.5배. U 이내인 자리 1%.
- 방향: 0단계에서 V0 는 정적 값에서 크게 벗어났고(0단계 D 중앙값 2.96), V1 은 V0 에서 정적 쪽으로 되돌아갔다. 되돌아간 비율 r = ⟨V1−V0, S−V0⟩/|S−V0|² 중앙값 0.45(사분위 0.38~0.92), 66자리 중 53자리에서 V1 이 V0 보다 정적에 가깝다. 부호 반전(V0−T0 와 V1−T1 의 가중평균 부호가 바뀜) 62/70.
- 반반 섞기를 이미 한 BB 씨앗 4자리: D 0.63→0.30, 0.42→0.36, 0.59→0.41, 0.40→0.43. V0−T0 와 V1−T1 의 모양 상관은 +0.56~+0.78(같은 방향으로 남은 오차), 평균 부호는 +→−, −→− 로 일정치 않다.
- 결론: V 자체가 단계마다 크게 움직인다. 처음 표를 만드는 끝점은 규칙상 V 를 100% 넣는데(알파 1.0), 그 한 번의 큰 점프가 레인지를 바꿔 다음 단계 V 가 정적 쪽으로 되돌아오는 진동 형태이다. 반반 섞기가 넘쳐서 생긴 진동이 아니라, 감쇠가 없는 첫 갱신의 진동이다(반반 섞기를 거친 4자리는 D 가 오히려 줄거나 비슷).
- 근거 한계: 표 있는 끝점은 4자리뿐이라 "반반 섞기 진동 없음"은 표본이 작다. 2단계에서 이 4자리 외의 끝점도 반반 섞기를 거쳐야 정확히 분류된다.
