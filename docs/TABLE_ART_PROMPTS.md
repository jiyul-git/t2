# 1인칭 테이블 캐릭터 그림 주문서 (Gemini용, 2026-10-26)

`docs/presentation-spec.md` 4장(상대 표시)과 7장(내 손)에 들어갈 캐릭터 그림을 주문하는 문서다.
라운지 주문서(`docs/LOUNGE_ART_PROMPTS.md`)와 같은 방식으로 진행한다: 기준 그림 한 장을 먼저 만들고, 그 그림을 첨부해 "이것만 바꿔" 로 고친다.

## 무엇을 그림으로, 무엇을 코드로

| 대상 | 방식 | 이유 |
|---|---|---|
| **상대 상반신과 손** | **2D 그림** (사용자가 Gemini 로 만든다) | 상대는 테이블 너머에 세운 판이다. 손 동작은 자세 그림 몇 장을 바꿔 끼우고 살짝 움직여서 만든다 |
| **내 손** | **3D 로우폴리** (코드로 만든다, 그림 필요 없음) | 내 손은 카드를 들추고 칩을 집는 등 각도가 계속 바뀐다. 2D 그림으로는 동작마다 수십 장이 필요하다. 캐릭터별 털·피부 색, 소매 색, 무늬(호랑이 줄무늬 등)를 코드로 입힌다 |

## 캐릭터 9명 (순서는 `ui/web/assets/portraits/01~09.png`)

| 번호 | 캐릭터 | 손(피부·털) | 소매(저고리) | 손 특징 |

| 01 | 갓 쓴 남자 | 살구색 | 초록 | 사람 손 |

| 03 | 머리띠 남자 | 살구색 | 노랑 | 사람 손 |
| 04 | 호랑이 | 주황 + 검은 줄무늬 | 초록 | 둥근 앞발, 발등에 줄무늬 |
| 05 | 크림 강아지 | 크림 | 파랑 | 둥근 앞발 |

## 공통 지시문 (모든 요청 끝에 붙인다)

```
[공통 규칙]
- 첨부한 그림의 캐릭터와 똑같은 캐릭터로 그려 줘(얼굴, 옷, 색, 선 굵기, 그림체 그대로).
- 정면에서, 눈높이에서 본 모습. 허리부터 머리까지만, 한 명만.
- 앞에 보이지 않는 테이블이 허리 높이에 있다고 생각하고, 팔꿈치와 손은 그 테이블 윗면 높이에 둬.
- 테이블, 카드, 칩, 의자 같은 물건은 그리지 마(요청에서 따로 말한 것만 그려).
- 배경은 완전히 흰색 단색. 그림자, 글자 없이.
- 가로 4:3 비율. 캐릭터 크기와 위치는 첨부한 그림과 똑같이.
```

- **머리까지 그리게 하는 이유:** 이미지 AI 는 머리 없는 몸을 잘 못 그린다. 머리까지 그리게 하고, 목에서 자르는 일은 내가 한다. 게임에서는 얼굴이 화면 밖이라 안 보인다.
- 테이블을 그리지 않는 이유: 테이블은 3D 장면에 있고, 그림은 그 뒤에 세운다. 테이블 윗면 높이에서 아래는 테이블에 가려진다.

## 진행 순서와 장수

**한 캐릭터(거북이 추천: 손 모양이 사람에 가까워 기준 잡기 쉽다)의 1단계 3장을 먼저 보내 주면** 내가 잘라서 시제품 테이블에 세워 보고, 괜찮으면 나머지 8명을 이어 간다.

| 단계 | 자세 | 캐릭터당 | 9명 | 쓰임 |
|---|---|---|---|---|
| 1단계 (필수) | ① 대기 ② 한 손 뻗기 ③ 두 손 뻗기 | 3장 | 27장 | ① 평소 ② 콜·벳·레이즈·폴드·체크(움직임으로 구분) ③ 올인 |
| 2단계 | ④ 손끝으로 톡톡 ⑤ 카드 뒤집기 ⑥ 팟 끌어오기 | 3장 | 27장 | 체크, 쇼다운, 승리를 따로 보여 줌 |
| 3단계 (선택) | ⑦ 팔짱 ⑧ 칩 셔플 | 2장 | 18장 | 체크 스타일 '팔짱', 셔플 버튼을 상대에게 보여 줌 |

1단계만 있어도 모든 액션이 돌아간다. 체크는 ② 를 작게 내렸다 올리는 움직임으로, 폴드는 ② 와 카드 날아가는 연출로 대신한다.

## 1단계 (캐릭터당 3장)

### ① 기준 그림: 대기 — `거북이_대기`

초상화 `09.png` 를 첨부하고:

```
이 캐릭터의 허리 위 상반신을 그려 줘. 두 팔은 앞으로 내려 팔꿈치를 몸 옆에 두고, 두 손은 몸 앞 테이블 높이에 가볍게 모아 둔 모습. 손에는 아무것도 들지 않은 상태. 차분한 표정.
[공통 규칙]
```

이 그림이 나머지 모든 그림의 기준이다. 마음에 들 때까지 이것만 다시 뽑는다. 이후 요청은 모두 **이 기준 그림을 첨부**한다.

### ② 한 손 뻗기 — `거북이_한손`

```
첨부한 그림에서 오른팔만 바꿔 줘. 오른손을 테이블 위 앞쪽(보는 사람 쪽)으로 쭉 뻗어 손바닥을 아래로, 무언가를 앞으로 미는 모습. 왼손과 몸, 얼굴은 그대로.
[공통 규칙]
```

- 캐릭터의 오른손은 보는 사람 기준 **왼쪽**이다. 헷갈려서 반대 손을 뻗으면 그대로 받아도 된다(좌우 뒤집어 쓴다).

### ③ 두 손 뻗기 — `거북이_두손`

```
첨부한 그림에서 두 팔을 바꿔 줘. 두 손을 테이블 위 앞쪽(보는 사람 쪽)으로 쭉 뻗어, 앞에 있는 것을 두 손으로 감싸 미는 모습. 몸과 얼굴은 그대로.
[공통 규칙]
```

## 2단계 (캐릭터당 3장)

### ④ 톡톡 — `거북이_톡톡`
```
첨부한 그림에서 오른손만 바꿔 줘. 오른손을 몸 앞 테이블 높이에 두고, 검지만 펴서 테이블을 톡 두드리는 모습.
[공통 규칙]
```

### ⑤ 카드 뒤집기 — `거북이_뒤집기`
```
첨부한 그림에서 오른손만 바꿔 줘. 오른손을 몸 앞 테이블 높이에서 손바닥이 위를 보도록 뒤집으며 무언가를 펼쳐 보이는 모습. 카드는 그리지 마.
[공통 규칙]
```

### ⑥ 팟 끌어오기 — `거북이_끌어오기`
```
첨부한 그림에서 두 팔을 바꿔 줘. 두 팔을 테이블 위 앞쪽으로 넓게 벌려 뻗었다가 몸 쪽으로 무언가를 끌어 모으는 모습. 기분 좋은 표정.
[공통 규칙]
```

## 3단계 (선택)

### ⑦ 팔짱 — `거북이_팔짱`
```
첨부한 그림에서 두 팔을 바꿔 줘. 테이블 높이에서 두 팔뚝을 앞으로 포개 팔짱을 낀 모습(오른팔이 위). 오른손 끝이 왼팔 위에 놓여 있다.
[공통 규칙]
```

### ⑧ 칩 셔플 — `거북이_셔플`
```
첨부한 그림에서 오른손만 바꿔 줘. 오른손을 몸 앞 테이블 높이에 두고, 손끝으로 작은 원판 더미 두 개를 섞는 모습. 원판은 빨강과 남색, 손가락 사이에 작게.
[공통 규칙]
```

## 받은 뒤 내가 하는 일

1. 흰 배경을 지우고(`art/tools/cutout_white.py`), 원본은 `art/sources/table/` 에 WebP 로, 자른 것은 `art/cutouts/table/<번호>_<자세>.png` 로 둔다.
2. 목 바로 아래에서 자른다. 자르는 높이는 ① 기준으로 캐릭터마다 한 번 정하고, 같은 캐릭터의 다른 자세에도 그대로 쓴다.
3. ① 과 다른 자세의 몸 위치가 어긋나면 어깨선을 기준으로 맞춘다.
4. 시제품 테이블에 세워 자리별 구도에서 확인하고, 스크린샷을 보낸다.
