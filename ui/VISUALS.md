# 한옥 테이블 UI 적용

기준 브랜치: `integration/ui-v49-money-jump-20260920` (`2610ec9`).

- 서버의 `n_slots`가 좌석 수를 결정합니다. 기본 9max를 대상으로 조정했고 기존 8/6 좌석 렌더링도 유지합니다.
- 일반 테이블에 한옥 배경과 청록색 펠트를 적용합니다. 파이널 테이블 자동 전환이나 새 게임 모드는 추가하지 않습니다.
- 카드 뒷면은 청록 창살 문양 한 종류이며 덱, 상대 카드, 히어로 카드, 공개 애니메이션이 동일한 CSS를 공유합니다.
- 승인한 방향의 기본 캐릭터 9종(사람 3, 실제 동물 6)을 우선 연결합니다. 500종 제작 시안 전체를 개별 배포용 파일로 전환한 상태는 아닙니다. 현재 같은 캐릭터가 반복 배정될 수 있습니다.
- 캐릭터 배정은 공개된 pid를 기준으로 고정됩니다. 자리 이동으로 외형이 바뀌지 않습니다.
- 몸과 얼굴은 정면이며 눈동자만 펠트 중앙을 향합니다. 이동량은 초상 폭의 2.9% 이내입니다. 게임 RNG나 봇 내부값은 사용하지 않습니다.
- PNG 아틀라스와 배경은 로컬 정적 자산입니다. 카메라, 외부 이미지 서비스, 추가 런타임 라이브러리가 필요하지 않습니다.

## 실행 폴더 갱신

기존 절차대로 `python ui/tools/setup_run_dir.py <별도 실행 폴더>`를 실행합니다.
Windows 스크립트도 `web/assets/`를 재귀 복사하도록 보완했습니다. 셸 버전은 기존부터 재귀 복사합니다.
진행 중인 게임 상태 파일은 복사하거나 변경하지 않습니다.

## 검증

```sh
node --check ui/web/app.js
node ui/tools/test_visuals.cjs
python ui/tools/test_setup_assets.py
# Playwright 및 Edge가 설치된 개발 환경에서:
node ui/tools/test_visuals_browser.cjs
```

브라우저 검증은 로컬 fixture 서버만 사용합니다. 엔진을 실행하거나 실제 게임 API를 호출하지 않습니다.
390×844 및 320×640 세로 화면, 9자리, 이미지 로딩, 시선 방향, 리사이즈 시 카드 DOM 유지,
레이즈 확인 버튼, 기존 8/6 슬롯 렌더링을 확인합니다.
