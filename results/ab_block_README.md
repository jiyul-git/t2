# block 복구 A/B 실험 결과 (2026-09-11)

실험 브랜치 `exp/block-elif` 에서 측정하고 브랜치는 폐기했다.
현재 브랜치의 `plan.py` 는 3dc5a48 상태 그대로다 (검증: `git diff 3dc5a48 -- plan.py` 비어 있음).

## 패치 — "한 줄"로는 불가능했다

    447  if sk('blockbet') >= 1 and rng.random() < block_p:   # 독립 if
    ...  _mg / _pc_p 계산
    456  if sk('potcontrol') >= 1 and rng.random() < _pc_p:

447 을 elif 로 바꾸면 442 의 `if oop and not initiative ...` 에 연결되어
의미가 뒤집힌다. 456 을 elif 로 바꾸면 사이의 `_mg`/`_pc_p` 계산이
if 와 elif 사이에 끼어 **문법 오류**가 된다.

그래서 쓴 최소 변경(6줄 추가, 2줄 수정):

    _blocked = (sk('blockbet') >= 1 and rng.random() < block_p)
    if _blocked: plan = 'block'; ...
    ...
    _pc_hit = (sk('potcontrol') >= 1 and rng.random() < _pc_p)
    if _blocked:   pass          # block 을 덮지 않는다
    elif _pc_hit:  plan = 'pot_control'; ...

조건식·임계값·확률계수는 하나도 바꾸지 않았고, **rng 소비 순서도 보존**했다
(두 random() 호출이 같은 순서로 그대로 실행된다).

  새 플레이어 착석 때 같은 rng 를 소비하기 때문)

## 판정에 쓸 수 있는 것 / 없는 것

쓸 수 있다 — 복구는 의도대로 작동한다. block 이 34/36 생존하고
다른 계획 분포는 거의 그대로다.

쓸 수 없다 — **EV 개선 여부는 이 표본으로 판정할 수 없다.**
