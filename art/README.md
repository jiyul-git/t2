# 라운지 그림 자료

사용자가 Gemini로 만들어 보낸 그림과, 그것을 정리한 결과물. 장면 엔진(`ui/web/lounge/`)에는 아직 연결되지 않았다.

## `lounge_bg/` 정리된 배경 레이어

2490×1728, 서로 정렬됨(선 일치율 98% 이상). 자세한 내용은 `lounge_bg/README.md`.

## `cutouts/` 누끼 딴 것 (투명 PNG)

| 파일 | 비고 |
|---|---|
| `plane_right.png`, `plane_left.png` | 바퀴 아래 옅은 그림자 자국이 조금 남음. 장면에 넣을 때 정리 |
| `sit_<캐릭터>.png` | 단체 그림을 세로로 잘라 나눔. 서로 맞닿은 부분(호랑이 꼬리, 토끼 캐리어)은 잘릴 수 있음 |
| `walk_<캐릭터>.png` | 같은 방식. 캐리어가 옆 캐릭터 쪽으로 넘어간 부분이 섞일 수 있음 |

단체 그림에서 자른 캐릭터는 확인·시험용이다. 실제 장면에는 캐릭터별로 따로 받은 그림(`docs/LOUNGE_ART_PROMPTS.md`)을 쓴다.

## `tools/`

- `cutout_white.py` — 흰 배경 그림의 배경과 바닥 그림자를 투명하게 하고 물체별로 저장한다. `--split N`은 맞닿은 여러 캐릭터를 빈 세로줄 기준으로 나눈다.

배경 정렬·워터마크 제거·AI 업스케일 과정은 `lounge_bg/README.md`에 적었다.

## 호랑이 걷기 시트 (`sources/tiger_walk_sheet_4x4_gemini.webp`)

Gemini가 "16장 모두 오른쪽"이라고 했지만 실제로는 섞여 있다. 빈 여백 기준으로 16칸을 잘라 `cutouts/tiger_walk/f_<행><열>.png`에 두었다.

| 칸 | 실제 방향 | 쓰임 |
|---|---|---|
| 1행 전부, 2행 전부 (`f_00`~`f_13`) | **왼쪽으로** 걷기, 8장 | 왼쪽 걷기 루프 |
| 3행 1열 (`f_20`) | 정면에 가까움, 캐리어 안 보임 | 돌아서기 후보 |
| 3행 2~3열 (`f_21`, `f_22`) | 오른쪽, 폰 든 손이 다름 | 제외 |
| 3행 4열, 4행 전부 (`f_23`, `f_30`~`f_33`) | **오른쪽으로** 걷기, 5장 | 오른쪽 걷기 루프 |

발밑에 옅은 그림자 자국이 조금 남아 있다.

## 호랑이 걷기 시트 2차 (`sources/tiger_walk_sheet_b1`~`b6.webp`)

같은 요청으로 받은 4×4 시트 6장. 어느 칸이 어느 방향인지는 그림을 보고 다시 확인했다(Gemini 설명은 맞지 않음).

| 시트 | 실제 내용 | 판정 |
|---|---|---|
| b1 | 16칸 모두 **왼쪽으로** 걷기. 다리 자세가 3가지(디딤 A, 지나가는 자세, 디딤 B)로 바뀜 | **사용** — 걷기 프레임 |
| b2 | 16칸 모두 오른쪽. 다리가 거의 같은 자세라 이어 붙이면 미끄러지듯 보임 | 보관만 |
| b3 | 2행이 크게 그려져 위아래 칸과 겹침 | 사용 불가 |
| b4 | 1칸에 캐리어 두 개, 행 간격 불규칙. 나머지는 오른쪽이지만 다리 변화 적음 | 보관만 |
| b5 | 1행 왼쪽, 나머지 오른쪽. 오른쪽 칸 다리 변화 적음 | 보관만 |
| b6 | 1~2행 왼쪽(다리 변화 있음), 3행 1칸 정면(캐리어 사라짐), 3행 2~3칸 캐리어 손이 바뀜, 나머지 오른쪽 | 돌아서기는 아직 못 씀 |

### `cutouts/tiger_walk_b/`

- `left_<행><열>.png` — b1을 2배로 키운 뒤(Real-ESRGAN anime) 빈 줄 기준으로 16칸으로 자름. 흰 배경, 바닥 그림자, 팔과 몸 사이 흰 틈은 투명. `left_33`은 Gemini 별 워터마크가 가슴에 남아 쓰지 않음.
- **`loop/left_0`~`7`, `loop/right_0`~`7` — 실제로 쓸 걷기 8프레임.** Gemini가 칸마다 얼굴·후드를 조금씩 다르게 그려서 칸을 그대로 이어 붙이면 얼굴이 부풀었다 줄고 `T2`가 깨졌다 붙는다. 그래서 윗몸(머리·후드·당기는 손·꼬리·손잡이·캐리어)은 `left_10` 한 장으로 고정하고, 후드 밑단 아래에서 `left_10` 위에 그은 경계선(`tools/lockbody.py`의 `EDGE`) 왼쪽, 즉 바지·주머니·발만 프레임마다 바꿨다. 경계선 오른쪽(손·손잡이·꼬리·캐리어)은 늘 같은 그림이라 깨지지 않는다. 다리 순서는 발을 재서 고른 한 걸음: `22 → 30 → 03 → 10 → 12 → 21` (뒷발 차고 들림 → 지나감 → 앞으로 나와 닿기 → 디딘 발이 뒤로 밀림). 양쪽 다리가 똑같이 생겨서, 디딘 발이 늘 뒤로만 가면 한 걸음 반복이 왼발·오른발 교대로 보인다. 제미나이는 반대발 자세를 끝내 못 그렸다(항상 화면 앞쪽 다리를 앞으로 냄). 밑단을 맞춘 뒤 발 위치 차이로 몸이 살짝 오르내린다.
- `loop/right_*` — `loop/left_*`를 좌우로 뒤집고 금색 `T2` 글자만 다시 뒤집어 바르게 읽히게 함.
- `walk_left.gif`, `walk_right.gif` — 위 8프레임 확인용 움직임.

도구: `tools/cut_sheet.py SHEET OUTDIR [행 열]`(칸 자르기), `tools/lockbody.py DIR BASE OUTDIR f1,f2,…`(윗몸 고정 + 다리 교체), `tools/mirror_logo.py IN OUT`(글자 유지 좌우 반전).
